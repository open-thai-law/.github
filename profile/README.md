# open-thai-law

เปิดกฎหมายไทยให้อ่าน ค้น และติดตามการแก้ไขได้ง่ายเหมือนอ่านโค้ด

| repo | คืออะไร |
|---|---|
| [**laws**](https://github.com/open-thai-law/laws) | กฎหมายไทย 1,899 ฉบับเป็น git repo: หนึ่งไฟล์ต่อหนึ่งฉบับ หนึ่ง commit ต่อการแก้ไขหนึ่งครั้ง ลงวันที่มีผลบังคับใช้ และระบุผู้ตรา ใช้ `git log -p` / `git blame` ดูได้ว่ามาตราไหนแก้เมื่อไร โดยใคร |

```sh
git clone https://github.com/open-thai-law/laws.git
```

> **ไม่ใช่ฉบับทางการ** และไม่ใช่คำแนะนำทางกฎหมาย ตรวจกับ[ราชกิจจานุเบกษา](https://ratchakitcha.soc.go.th)ทุกครั้ง

**ช่วยกันได้:** เจอข้อความผิด หรือกฎหมายที่แก้แล้วแต่ยังไม่อัปเดต แจ้งที่ [Issues ของ laws](https://github.com/open-thai-law/laws/issues/new/choose) ([วิธีแจ้ง](https://github.com/open-thai-law/laws/blob/main/CONTRIBUTING.md))

ข้อมูลเป็นสาธารณสมบัติ (CC0) ตัวบทกฎหมายไม่มีลิขสิทธิ์ตาม พ.ร.บ.ลิขสิทธิ์ พ.ศ. ๒๕๓๗ มาตรา ๗

---

**English:** Thai legislation as open data. [`laws`](https://github.com/open-thai-law/laws) holds 1,899 Thai acts, codes and constitutions as a git history, one commit per amendment. Unofficial; check the Royal Gazette. CC0.
